Model fleet operating contract

Default production posture for buyer-integrated provider, cloud and private model runtimes.

Production workloads route through stable aliases instead of hardcoding provider model identifiers throughout application code.

Model snapshot or provider-managed revisions trigger evaluation and lifecycle review before becoming the production baseline.

Quota, token throughput, request capacity and private-runtime queue pressure are monitored before they become user-facing failures.

Residency and compliance constraints filter candidate routes before quality, latency or cost optimization is applied.

Fallback routes must be independently evaluated and cannot silently weaken safety, grounding, authorization or residency requirements.

Every route decision records workload requirements, candidate filtering, selected route, fallback posture and runtime evidence.
