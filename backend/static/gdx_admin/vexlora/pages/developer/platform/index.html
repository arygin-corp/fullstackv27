Production request boundary

Recommended path for sensitive business applications.

1

Admin UI uses a secure buyer-owned session

2

Buyer BFF / backend validates actor, tenant and action

3

API gateway or service applies contract, quota and authorization

4

Provider or internal service returns normalized result

5

Events/webhooks are verified, deduplicated and queued

6

Domain state, audit evidence and observability are updated

Security boundary

What remains intentionally outside this frontend template.

Usable API secrets, client secrets and refresh tokens stay server-side.
OAuth callback exchange and token refresh happen in the buyer backend/BFF.
Webhook signature verification uses the original request body before processing.
Every write is re-authorized on the server even when the UI already hid the action.
Production API traffic requires buyer-owned services; the Explorer remains a safe sample surface.
