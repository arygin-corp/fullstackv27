Certification checklist

Source-level accessibility expectations for production-ready admin interfaces.

Skip-to-content is the first keyboard destination on application and auth screens.

Dashboard and authentication shells expose one focusable main-content landmark.

Icon-only buttons require an accessible name.

Checkbox and radio controls use a 24×24 CSS-pixel interactive target.

Dialog and sheet close controls retain visible focus and a screen-reader label.

Reduced-motion users do not receive essential spinner/skeleton/transform animation.

Native table column headers expose scope=col and DataTable exposes an accessible table name.

Standalone search, select, switch, checkbox, radio and textarea controls are labelled.
