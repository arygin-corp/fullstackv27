Operational command-center composition

Business command centers across AI, commerce and operations follow the same information hierarchy even when their domain content differs.

1. Context

Page title, scope, time range and the primary operating action.

2. Health

A small set of high-signal KPIs with semantic status and trend.

3. Attention

Owned exceptions, risks and approvals instead of another generic chart row.

4. Work

Queues, orchestration lanes or business records that the operator can act on.

5. Evidence

Trace, audit, source or policy context behind recommendations and decisions.

6. Handoffs

Deep links to specialist workspaces; command centers summarize rather than duplicate them.

Favorites

Favorite commands are stored locally per browser, so the template illustrates personalization without requiring a backend.

Recent items

The latest opened destinations are retained locally with a strict six-item limit instead of growing an uncontrolled history.

Extensible registry

Future modules register searchable resources and actions in one typed configuration rather than coupling them to the topbar component.
