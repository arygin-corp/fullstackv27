Reuse rule

Foundation is the first place to look before creating a new local UI pattern.

1. Reuse a primitive

Buttons, cards, dialogs, forms, tables and charts come from shared components.

2. Reuse a composition

Metric cards, workspace rails, timelines, status patterns and command-center sections solve recurring business layouts.

3. Create domain UI last

Feature components should contain business behavior or data shape—not duplicate styling already owned by Foundation.
