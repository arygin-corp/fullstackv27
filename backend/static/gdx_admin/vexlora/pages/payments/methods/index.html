Add payment method

Frontend configuration draft. A real provider must support the method for the selected market and currency.

Adding a method here never creates provider capability. The buyer's backend/provider account must request or enable the method and validate country/currency eligibility.

Country & currency

A method can be available only for specific business locations, customer countries and presentment currencies. The final eligibility matrix belongs to the connected provider.

Domain eligibility

The same method can be enabled for storefront checkout but disabled for recurring SaaS, invoices, rent, tuition or other flows.

Compliance boundary

The template stores no raw card/CVV data. Provider-hosted or tokenized payment collection is expected for production integrations.
