Access requests endpoints

Audience: API Consumers / ApproversIntermediate22 minv1.1.0Updated October 2026

Submit, inspect, approve, or reject governed product access requests

Submit request

POST /api/v1/apiaccessrequest/
Idempotency-Key: access-request-001

{
  "application": "22bfec5c-6218-4177-94f3-43a3f46f9001",
  "product": "5e47b6d0-5eac-4da7-8f45-2f092ab6c001",
  "requested_scopes": ["customer.read"],
  "intended_use": "Display customer profile in fulfillment workflow",
  "environment": "test"
}
{
  "id": "9fc94f8e-13c0-49ae-a18f-d68f15d26001",

}

Approval error

An approval may fail when the caller is not an assigned approver, the request is no longer pending, required evidence is absent, or tenant context does not match.

{
  "code": "TENANT_ACCESS_DENIED",
  "message": "The active identity is not authorized for this tenant.",
  "request_id": "req_01JEXAMPLE",
  "correlation_id": "corr_01JEXAMPLE"
}
