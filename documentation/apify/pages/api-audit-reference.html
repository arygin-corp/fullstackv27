API reference

Audit events endpoints

Audience: Auditors / Security / Platform OwnersAdvanced20 minv1.1.0Updated October 2026

Query tenant-scoped audit evidence without exposing redacted fields or unauthorized event categories

Query events

GET /api/v1/audit-events/?action=product.publish&outcome=success
Authorization: Bearer <token>
X-Apify-Tenant: <tenant-id>
{
  "count": 1,
  "results": [{
    "event_id": "evt_01JAUDIT",
    "action": "product.publish",
    "outcome": "success",
    "target_type": "ApiProduct",
    "target_id": "5e47b6d0-5eac-4da7-8f45-2f092ab6c001",
    "request_id": "req_01JEXAMPLE",
    "occurred_at": "2026-10-09T21:00:00Z"
  }]
}

Protection

Audit queries require authorized tenant context and audit permissions. Responses must preserve configured redaction and should not expose secret material in before, after, metadata, or error fields.

{
  "code": "TENANT_ACCESS_DENIED",
  "message": "The active identity is not authorized for this tenant.",
  "request_id": "req_01JEXAMPLE",
  "correlation_id": "corr_01JEXAMPLE"
}
