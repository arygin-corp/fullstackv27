API reference

API reference overview

Audience: Developers / API ConsumersIntermediate18 minv1.1.0Updated October 2026

Reference conventions for versioning, authentication, tenant context, pagination, idempotency, errors, and correlation

Base URL

Examples use /api/v1/. Replace the host and authentication mechanism with the deployed environment. Exact schemas must be verified against the deployed OpenAPI contract.

curl -H "Authorization: Bearer $TOKEN" \
     -H "X-Apify-Tenant: $TENANT_ID" \
     -H "Accept: application/json" \
     https://apify.example.internal/api/v1/apiproduct/

Standard error

Illustrative error envelope:

{
  "code": "TENANT_ACCESS_DENIED",
  "message": "The active identity is not authorized for this tenant.",
  "request_id": "req_01JEXAMPLE",
  "correlation_id": "corr_01JEXAMPLE"
}

Common status codes

200 success; 201 created; 202 accepted for asynchronous work; 400 invalid input; 401 unauthenticated; 403 unauthorized; 404 not found or intentionally concealed; 409 lifecycle or idempotency conflict; 429 runtime or management rate limit; 500 unexpected failure.
