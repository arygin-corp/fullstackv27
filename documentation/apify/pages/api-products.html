API product management

Audience: API Product Owner, Platform Owner, GovernanceIntermediate20 minv1.0.0Updated October 2026

Manage APIs as governed products with ownership, lifecycle, access, policy, support, and adoption commitments.

Lifecycle

  • Draft
  • Review
  • Approved
  • Published
  • Deprecated
  • Retired
  • Archived

Product definition

  • APIs and endpoints
  • Scopes and eligibility
  • Environment policy inheritance
  • Quotas and rate plans
  • Terms and data-sharing agreements
  • Business, technical, product, and stewardship ownership
  • SLAs, support, lineage, dependencies, and certification

Ongoing management

  • Version independently from proxy revisions.
  • Measure adoption, errors, latency, utilization, and approval SLA.
  • Run ownership recertification and duplicate detection.
  • Plan deprecation, consumer migration, replacement, and retirement.
