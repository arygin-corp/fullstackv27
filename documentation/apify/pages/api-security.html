Platform features

API security

Audience: Security, Engineer, Platform OwnerAdvanced22 minv1.0.0Updated October 2026

Protect identities, transports, payloads, credentials, configurations, and runtime operations.

Identity and transport

  • OAuth/OIDC and JWT validation
  • API keys where approved
  • mTLS and certificate lifecycle
  • Workload identity
  • Private networking and egress controls
  • Audience and scope restriction

Threat protection

  • Payload size, depth, and element limits
  • Schema and OAS validation
  • Injection and malformed-content protection
  • Replay and credential-abuse detection
  • Bot, automation, and anomaly detection
  • Sensitive-data detection and masking

Security governance

  • Classification-based baselines
  • Policy-as-code and approved templates
  • Expiring waivers
  • Posture scores and remediation SLAs
  • Shadow, zombie, undocumented, and unmanaged API discovery
  • Emergency revocation and rotation
