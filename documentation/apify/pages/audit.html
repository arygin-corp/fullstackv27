Platform features

Comprehensive audit logging

Audience: Auditor, Security, Platform Owner, OperationsAdvanced20 minv1.0.0Updated October 2026

Capture tenant-aware business, security, operational, HTTP, and integration events with redaction and tamper-evident sequencing.

Event contents

  • Tenant and team
  • Actor and identifier
  • Event type, category, action, outcome, and severity
  • Object type and ID
  • Request, correlation, and idempotency IDs
  • Source IP, user agent, method, path, and status
  • Redacted before/after state and metadata
  • Error code, message, timestamp, previous hash, and event hash

Automatic coverage

Record state-changing requests, exceptions, access grants and denials, privileged changes, credential operations, deployments, approvals, security findings, exports, and recovery actions.

Production controls

  • SIEM export
  • Immutable/WORM retention
  • Retention classes and legal hold
  • Auditor access review
  • Alert rules
  • Export health and reconciliation
  • Trusted proxy parsing
  • Batch signing or external anchoring where required
