Developer guide

Tenant-owned model example

Audience: DevelopersAdvanced20 minv1.1.0Updated October 2026

Implement tenant-owned persistence with explicit ownership, lifecycle fields, and database constraints

Illustrative model

The following implementation is an illustrative reference aligned to the documented architecture. Adapt field names, permissions, and provider calls to the deployed source version and validate them with tests before production use.

import uuid
from django.db import models

class ApiProduct(models.Model):
    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    tenant = models.ForeignKey("tenancy.Tenant", on_delete=models.PROTECT)
    owning_team = models.ForeignKey("tenancy.EnterpriseTeam", on_delete=models.PROTECT)
    name = models.CharField(max_length=200)
    slug = models.SlugField(max_length=220)
    lifecycle = models.CharField(max_length=32, default="draft")
    version = models.PositiveIntegerField(default=1)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        constraints = [
            models.UniqueConstraint(fields=["tenant", "slug"], name="uq_product_tenant_slug")
        ]
        indexes = [models.Index(fields=["tenant", "lifecycle"])]

Validation rules

Validate that owning_team belongs to the same tenant. Preserve records referenced by subscriptions, deployments, or audit evidence according to retention policy.
