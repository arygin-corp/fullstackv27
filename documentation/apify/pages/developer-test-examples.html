Developer guide

Test implementation examples

Audience: Developers / QAAdvanced24 minv1.1.0Updated October 2026

Write tests that prove tenant isolation, lifecycle validation, idempotency, audit behavior, and adapter conformance

Tenant isolation test

The following implementation is an illustrative reference aligned to the documented architecture. Adapt field names, permissions, and provider calls to the deployed source version and validate them with tests before production use.

def test_product_detail_is_not_visible_cross_tenant(api_client, user, tenant_a, tenant_b):
    product = ApiProductFactory(tenant=tenant_b)
    grant_membership(user, tenant_a)
    api_client.force_authenticate(user)
    response = api_client.get(
        f"/api/v1/apiproduct/{product.id}/",
        HTTP_X_APIFY_TENANT=str(tenant_a.id),
    )
    assert response.status_code in {403, 404}

Idempotency test

def test_duplicate_deploy_uses_same_provider_operation(service, revision, environment):
    key = "deploy-123"
    first = service.deploy(revision, environment, idempotency_key=key)
    second = service.deploy(revision, environment, idempotency_key=key)
    assert first.id == second.id
    assert service.adapter.deploy_call_count == 1
