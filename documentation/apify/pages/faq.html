Frequently asked questions

Audience: All audiencesBeginner12 minv1.0.0Updated October 2026

Quick answers to common platform and documentation questions.

Is Django the production gateway?

No. Django is the control plane. Production traffic requires a certified gateway data plane.

Who owns the platform?

The Data Marketplace Team is the platform-owner team, but each user still needs app_access and linked platform_owner group membership for full owner authority.

Can a tenant administrator see another tenant?

No. Tenant-owned querysets and action checks must fail closed outside the active authorized tenant.

Are secrets stored in the database?

The production design stores secret references and fingerprints, not plaintext values.

What makes a capability A+?

Passing documented architecture, security, tenancy, scale, recovery, audit, accessibility, monitoring, runbook, and ownership evidence gates.

Can Apify support multiple gateway vendors?

The architecture defines a provider-neutral GatewayAdapter. Each provider must be implemented and certified separately.
