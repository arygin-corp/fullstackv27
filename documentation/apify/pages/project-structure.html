Getting started

Project structure

Audience: EngineerIntermediate12 minv1.0.0Updated October 2026

Understand where cross-cutting, tenancy, platform, runtime, audit, templates, and configuration concerns live.

Key directories

  • config/: settings, URLs, ASGI/WSGI, and capability metadata.
  • apps/tenancy/: tenants, teams, memberships, access groups, ownership, middleware, and permissions.
  • apps/platform/: APIs, products, proxies, deployments, policies, applications, subscriptions, analytics, governance, pipelines, security records, and outbox.
  • apps/runtime/: GatewayAdapter contracts and provider implementations.
  • apps/audit/: append-only event model, redaction, request middleware, exports, and administration.
  • apps/apify/: API routing and documentation/admin shell.
  • templates/ and static/: portal presentation assets.

Design rule

Business behavior belongs in domain services. Provider-specific behavior belongs in adapters. Views remain thin, tenant-aware, and action-authorized.
