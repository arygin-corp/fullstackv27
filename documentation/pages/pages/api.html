25. API Reference

Read-only authenticated page API.

Routing

The DRF router registers pages at pages under the configured API prefix.

Access behavior

The PageViewSet is read-only and requires authentication. Its queryset applies visible_pages and selects the published version.

Page fields

id, title, slug, page_type, locale, published, and updated_at. The nested published version exposes id, number, title, summary, content, status, and created_at.

Integration checklist

Validate the consuming integration.
