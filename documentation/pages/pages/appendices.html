29. Appendices and Reference

Glossary, status reference, and operational templates.

Glossary

Page: governed content record. Working version: current editable version pointer. Published version: public/current version pointer. Requirement: required review record. Task: assigned unit of workflow work. Approval: reviewer decision. Lifecycle request: archive/delete request. Audit event: immutable history record.

Status reference

Version statuses: Draft, Content Review, Specialist Review, Approved, Revision Requested, Rejected, Published, Superseded. Task statuses: Open, Claimed, Completed. Notification statuses: Pending, Sent, Failed. Schedule statuses: Pending, Running, Completed, Failed, Canceled.

Decision comment template

Recommended practice: State the scope reviewed, the result, specific findings, required changes, and any follow-up owner. This template is guidance, not an application-enforced format.
