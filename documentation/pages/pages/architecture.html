2. Application Architecture

Core objects and how they relate.

Page

A Page stores the title, slug, page type, locale, owner group, review flags, published-version pointer, working-version pointer, archive state, and deletion state.

Page version

A PageVersion stores numbered content, summary, SEO fields, status, author, submission metadata, and an optional replaced-version relationship.

Workflow and review

ReviewRequirement records the required review type and group. WorkflowTask records the task type, assigned group, status, due date, and completion date. Approval stores the reviewer, reviewer group, decision, comment, and timestamp.

Supporting objects

MediaAsset records uploaded files and scan status. NotificationDelivery records delivery channel and status. AuditEvent captures immutable audit data. ScheduledPublication records scheduled publish or unpublish work.
