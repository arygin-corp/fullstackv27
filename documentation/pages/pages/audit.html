21. Audit and Compliance

Immutable event history and review guidance.

Immutability

Existing AuditEvent records cannot be updated and cannot be deleted through the model behavior. Audit records include page snapshot data, version number, action, actor, authority group, details, and timestamp.

Audit review procedure

Review immutable audit records for the defined scope.

  1. Open Audit.
  2. Filter or inspect events relevant to the review scope using available application capabilities.
  3. Confirm page slug snapshot, version number, action, actor, and details.
  4. Document findings outside the immutable record when follow-up is required.
