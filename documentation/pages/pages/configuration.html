26. Installation and Enterprise Configuration

Host integration and production dependencies.

Compatibility

The supplied package targets Django 4.2.30, Python 3.8 through 3.12, Django REST Framework 3.15.2, and Celery 5.4 entry points.

Host integration

Install rest_framework, django_filters, and apps.pages.apps.PagesConfig; add project URLs for the Pages UI and API; configure template directories, media, email, Celery, and storage.

Production requirements

The supplied configuration document calls for broker/result backend, worker scheduler, email backend, durable object storage, malware scanning, database-level append-only audit enforcement, authentication/SSO, secrets, backups, monitoring, and publication/CDN adapters.

Deployment checklist

Validate host and production configuration.
