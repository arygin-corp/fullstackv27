10. Content Manager Guide

Create and update pages; submit eligible versions; complete assigned content reviews; publish approved versions.

Approval criteria for Content Manager

Recommended operating criteria; the application enforces only status, group, and comment rules.

  • ☐Page metadata and classification are complete.
  • ☐Content uses supported blocks and passes validation.
  • ☐Title, summary, links, images, captions, and FAQ entries have been reviewed.
  • ☐Required specialist flags are set before submission.
  • ☐Reviewer comments have been addressed in a new version where required.
  • ☐No open workflow task remains before treating the version as ready.
  • ☐Version status is Approved before Publish is selected.

Escalation path

Recommended organizational process when the normal path cannot complete.

  1. If the page is not visible, ask an Administrator to validate group membership, ownership, publication, archive, and deletion state.
  2. If a required task is missing or assigned to the wrong group, stop the workflow and escalate to an Administrator or application owner before recording decisions.
  3. If legal or security meaning is disputed, route the question to the corresponding specialist group and do not publish until resolved.
  4. If Publish fails, verify Content Manager authority and Approved status; then escalate the error and page/version identifiers to platform support.
  5. If an audit discrepancy is suspected, preserve the immutable record and escalate through the audit/compliance process.

Role purpose

Create and update pages; submit eligible versions; complete assigned content reviews; publish approved versions.

Procedure

Follow the implemented application flow for the role.

  1. Confirm page metadata and ownership.
  2. Create or update the working version.
  3. Preview and compare as needed.
  4. Submit Draft or Revision Requested content.
  5. Complete assigned content review tasks.
  6. Track specialist review completion.
  7. Publish only the Approved version.
  8. Verify page and version status after publication.
