4. Dashboard and Navigation

Purpose of every routed application area.

Dashboard

Displays pages visible to the user and a task list filtered to the user’s groups.

Primary areas

Routes exist for Pages, Workflow, Tasks, Approvals, Ownership, Notifications, Audit, Retention, Search, Governance, Inventory, Analytics, and Health.

How to choose an area

Use Pages for page records and versions; Workflow or Tasks for assigned work; Approvals for approval history; Ownership for pages with owner groups; Governance for DRB-scoped pages; Retention for deleted pages; Audit for event history; Analytics and Health for operational summaries.
