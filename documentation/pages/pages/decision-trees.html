Decision Trees

Fast choices for creation, submission, review, publication, and restore.

Should I create a page or edit one?

Does the slug + locale already exist? ├─ No → Create a new page and initial version. └─ Yes → Open the existing page and use Edit to create a new version. Never create a duplicate page merely to revise content.

Can I submit this version?

Is there a working version? ├─ No → Create or edit content first. └─ Yes → Is status Draft or Revision Requested? ├─ No → Do not submit; inspect current workflow/status. └─ Yes → Preview, confirm review flags, and Submit.

Which review decision should I use?

Are required changes needed? ├─ No → Is the review successful with no material comment? │ ├─ Yes → Approved │ └─ No → Approved with comments └─ Yes → Should the content be corrected and resubmitted? ├─ Yes → Revision requested └─ No → Rejected If unable to make the review determination → use the approved organizational escalation; Abstained exists but business handling must be locally defined.

Can I publish?

Is the intended version Approved? ├─ No → Do not publish. Complete or correct the workflow. └─ Yes → Does the account satisfy Content Manager authority or authorized superuser behavior? ├─ No → Contact an authorized Content Manager or Administrator. └─ Yes → Publish and validate the result.

Can I restore a deleted page?

Is the page marked deleted? ├─ No → Restore does not apply. └─ Yes → Is purge_at still in the future? ├─ No → Restore is unavailable in the supplied service. Escalate. └─ Yes → Restore and verify state.
