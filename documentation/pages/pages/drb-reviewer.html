15. Data Review Board Guide

View non-deleted pages marked as requiring DRB review through the governance view.

Governance review criteria

These are recommended operating criteria unless stated as application-enforced.

  • ☐The page is marked as requiring DRB review.
  • ☐The page is not deleted.
  • ☐The correct page/version and owner are identified.
  • ☐The outcome is recorded using the organization’s approved DRB process.

Escalation steps

Use the approved organizational channel for each escalation.

  1. If a formal DRB task or decision is expected, escalate because the supplied workflow types do not include a DRB review task.
  2. If the page is absent from Governance, ask an Administrator to verify the DRB flag and visibility.
  3. Escalate unresolved governance ownership to the designated governance authority.

Role purpose

View non-deleted pages marked as requiring DRB review through the governance view.

Procedure

Follow the implemented application flow for the role.

  1. Open Governance.
  2. Confirm the page is marked as requiring DRB review.
  3. Open the page and available version.
  4. Use assigned organizational procedures for any review action outside the implemented task types.

Completion checklist

Use this checklist before closing the activity.
