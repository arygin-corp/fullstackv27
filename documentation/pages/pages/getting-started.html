3. Getting Started

Access, navigation, and first-use checks.

First-time application tour

Use this sequence to learn the application without changing content.

  1. Open Dashboard to see pages visible to the signed-in account and tasks assigned to the account’s groups.
  2. Open Pages to review the searchable inventory of visible pages.
  3. Open one page and identify the working version or published version shown on Page Detail.
  4. Open Versions to see numbered historical versions.
  5. Open Workflow and Tasks to see work assigned to the account’s groups.
  6. Open Approvals to review recorded decisions.
  7. Open Ownership, Governance, Notifications, Audit, Retention, Analytics, and Health to understand the available operational views.
  • ☐The expected pages are visible.
  • ☐The expected group tasks are visible.
  • ☐The user knows which functions are view-only and which change data.
Important: Screen labels can vary with the host templates. Route names and behavior in this manual come from the supplied application files.

Choose the correct starting path

Select the path matching the work to be performed.

  1. To create content, begin in Pages and use New Page.
  2. To revise content, open the page and use Edit; saving creates a new version.
  3. To review content, begin in Workflow or Tasks.
  4. To publish, open an approved working version while using an account authorized by the publish service.
  5. To investigate history, use Versions, Approvals, and Audit.
  6. To locate content, use Search, Inventory, or Ownership.

Access prerequisites

Users must be authenticated. Visibility and task access depend on Django group membership and page settings.

First-use procedure

Use the dashboard to view visible pages and up to ten tasks assigned to groups associated with the signed-in account.

  1. Sign in through the host project authentication experience.
  2. Open the Pages dashboard.
  3. Confirm that expected pages are visible.
  4. Confirm that expected workflow tasks appear.
  5. Open Notifications to confirm the account-specific notification list.
