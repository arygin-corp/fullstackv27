12. Product Owner Guide

Review owned pages when visibility is enabled and provide business-owner input when a corresponding task is available.

Business approval criteria

These are recommended operating criteria unless stated as application-enforced.

  • ☐The page belongs to the correct owner group.
  • ☐Working-version access is enabled when review is expected.
  • ☐Product facts, terminology, ownership, and links are accurate.
  • ☐Requested changes are explicit and actionable.

Escalation steps

Use the approved organizational channel for each escalation.

  1. If the page is not visible, ask an Administrator to validate owner-group spelling, membership, and the working-version flag.
  2. If no product review task exists, ask the Content Manager or Administrator to verify page flags and task generation.
  3. Escalate unresolved factual ownership questions through the product governance process.

Role purpose

Review owned pages when visibility is enabled and provide business-owner input when a corresponding task is available.

Procedure

Follow the implemented application flow for the role.

  1. Confirm the signed-in account belongs to the page owner group.
  2. Open the owned page.
  3. Confirm working-version visibility is enabled.
  4. Review title, summary, content, and business accuracy.
  5. Record a decision if an assigned workflow task exists.

Completion checklist

Use this checklist before closing the activity.
