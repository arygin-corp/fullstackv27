Start Here: New Employee Path

A self-guided route from first sign-in to independent daily work.

Your goal

Complete the guided path below before performing unsupervised production work. This manual explains application behavior from the supplied source and labels organizational criteria as recommended guidance.

  1. Identify the user group assigned to the account.
  2. Read the screen guide and locate each major area without changing data.
  3. Complete the Create a Page playbook in an approved training environment.
  4. Complete the Update and Submit playbook.
  5. Complete the role-specific approval or publication playbook.
  6. Practice one exception runbook.
  7. Complete the knowledge check and retain the completion checklist.

What this manual can answer

The package covers where to start, what each screen is for, how to create and update pages, how versions work, how to submit content, how reviews and decisions work, how approved content is published, how to find records, how to handle common failures, and when to escalate.

What still requires organizational input

The supplied source does not define your organization’s production URL, support contacts, service-level targets, legal approval standard, security standard, DRB decision process, naming convention, or training environment. The package provides editable placeholders and clearly marks these as local configuration.

Before rollout: replace every [LOCAL ...] placeholder in the ownership and escalation chapter.

First hour checklist

Use this as the first independent onboarding activity.

  • ☐I can open the manual home page.
  • ☐I know my assigned application group.
  • ☐I can find Dashboard, Pages, Workflow, Tasks, Approvals, Notifications, and Search.
  • ☐I understand the difference between a page and a page version.
  • ☐I understand that publishing requires an Approved version.
  • ☐I know where to find the escalation map.
