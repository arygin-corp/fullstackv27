17. Super Administrator Guide

Elevated-action criteria

These are recommended operating criteria unless stated as application-enforced.

  • ☐The action requires elevated authority.
  • ☐The target page and version are confirmed.
  • ☐The least-privileged path was considered first.
  • ☐The result and audit state were verified.

Escalation steps

Use the approved organizational channel for each escalation.

  1. Stop if the requested action would bypass organizational approval without authority.
  2. Escalate suspected data integrity or audit issues to platform and compliance owners.
  3. Document the business reason for elevated intervention outside the application if required by policy.

Procedure

Follow the implemented application flow for the role.

  2. Use the least-privileged account where possible.
  3. Perform the required supported operation.
  4. Review resulting audit and application state.
