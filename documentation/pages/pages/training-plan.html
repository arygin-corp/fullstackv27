Five-Day Self-Guided Training Plan

Exercises, expected outcomes, and readiness checks for a new employee.

Day 1: Orientation

  1. Read Start Here.
  2. Complete the safe screen tour.
  3. Define page, version, task, requirement, approval, and audit event.
Completion standard: Can navigate without changing data.

Day 2: Create and Preview

  1. Create a training page.
  2. Complete all metadata fields.
  3. Create structured content.
  4. Preview and verify version 1.
Completion standard: Can create a valid page in an approved training environment.

Day 3: Version and Submit

  1. Edit the training page to create version 2.
  2. Compare versions.
  3. Configure review flags.
  4. Submit and confirm tasks.
Completion standard: Can move eligible content into review.

Day 4: Review and Revise

  1. Complete a training review task.
  2. Use Revision Requested with an actionable comment.
  3. Create a corrected version and resubmit.
Completion standard: Can complete and respond to review work.

Day 5: Approve, Publish, and Recover

  1. Complete remaining training approvals.
  2. Verify Approved status.
  3. Publish using authorized training account.
  4. Create another revision and practice rollback.
Completion standard: Can complete the lifecycle and understand recovery behavior.

Supervisor-independent sign-off

A learner can use this self-check before requesting production access.

  • ☐I can create and edit a page.
  • ☐I can explain version history.
  • ☐I can submit only eligible statuses.
  • ☐I can verify generated tasks.
  • ☐I can record a supported review decision with an adequate comment.
  • ☐I can explain when a version becomes Approved.
  • ☐I can verify publish prerequisites.
  • ☐I can use search, inventory, approvals, and audit for investigation.
  • ☐I can follow an exception runbook.
  • ☐I know the configured local escalation contacts.
