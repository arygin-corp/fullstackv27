27. Troubleshooting

Symptoms, implemented causes, and validation steps.

Page is not visible

Check authentication, group membership, publication state, owner-group match, working-version visibility flag, DRB flag, archive state, and deletion state.

  1. Confirm signed-in account.
  2. Confirm group membership.
  3. Check page archived/deleted state.
  4. Check published version.
  5. For an owned page, check owner group and working-version visibility.
  6. For DRB, check the DRB review flag.

Version cannot be submitted

The submit service accepts only Draft or Revision Requested versions. Confirm a working version exists and has an eligible status.

Review decision fails

Confirm the account belongs to the task assigned group or is a Django superuser. Confirm comment length is at least 25 characters, or at least 50 for Rejected.

Publish fails

Confirm the account satisfies the Content Manager group check and that the version status is Approved.

Media upload fails

Confirm file MIME type is accepted and size is no more than 20 MB.

Notification fails

Review email configuration and the NotificationDelivery error payload. The retry task in the supplied file returns the failed count; it does not resend messages.
