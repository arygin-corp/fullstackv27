6. Version Management

Version numbering, comparison, revision, and rollback.

Version behavior

New version numbers are generated from the highest existing version plus one. New content is validated and sanitized before storage. The new version becomes the page working version.

Statuses

Draft, Content Review, Specialist Review, Approved, Revision Requested, Rejected, Published, and Superseded.

Compare versions

The compare route produces a unified difference of formatted JSON content between two versions.

  1. Open the page version list.
  2. Choose the two version numbers to compare.
  3. Review additions and removals in the generated difference.
  4. Return to the working version before editing.

Rollback

Rollback creates a new version from a selected source version; it does not rewrite the historical source.

  1. Open Versions.
  2. Open the source version.
  3. Open Rollback.
  4. Review the selected version.
  5. Submit the rollback action.
  6. Verify that a new working version was created.
