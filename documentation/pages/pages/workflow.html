8. Workflow Management

Submission, task generation, routing, and state transitions.

Tutorial: submit a version into approval workflow

Submission changes state and creates review requirements/tasks.

  1. Open the page and confirm a working version exists.
  2. Confirm the working version status is Draft or Revision Requested. Other statuses are not submittable by the supplied service.
  3. Review the page review flags before submission.
  4. Preview the working version and compare against the prior version when appropriate.
  5. Select Submit.
  6. Confirm the version status changes to Content Review.
  7. Open Workflow or Tasks and verify the Content Review task.
  8. Verify optional tasks for product, legal, and security review when their flags are enabled.
  9. Record any routing discrepancy before reviewers begin work.
  • ☐Eligible starting status.
  • ☐Content review task exists.
  • ☐Optional review tasks match page flags.
  • ☐Assigned group names are correct.
  • ☐Submitted-by information is present.
Important: The supplied service maps product review to the Content Manager Group. Confirm whether that implementation is intentional before relying on Product Team/Owner Group routing.

How approval state progresses

The supplied decision service changes the version according to reviewer decisions.

  1. Rejected immediately sets the version to Rejected.
  2. Revision requested immediately sets the version to Revision Requested.
  3. After another decision, if any version task remains Open, the version becomes Specialist Review.
  4. After another decision, if no version task remains Open, the version becomes Approved.
  5. Publishing is a separate action and accepts only an Approved version.

Submission behavior

Draft and Revision Requested versions can be submitted. Submission always creates a Content Manager requirement/task. Optional product, legal, and security flags add additional requirements/tasks. The supplied service assigns product review to the Content Manager Group.

Task lifecycle

Tasks use Open, Claimed, and Completed statuses. The reviewed decision service completes a task after saving the approval.

Submission procedure

Use this procedure to submit an eligible version.

  1. Confirm the page has a working version.
  2. Confirm the version is Draft or Revision Requested.
  3. Confirm page review flags.
  4. Select Submit.
  5. Verify Content Review status.
  6. Verify expected tasks were created.
