# Workflow Engine Docs V2

Generated static documentation portal.

- 550 numbered content pages
- 52 architecture diagram specification pages
- Full-site client-side search
- Responsive navigation
- Reusable HTML template
- API, data-model, operations, security, SDK, developer, and product collections

## Preview

```bash
cd workflow-engine-docs-v2
python -m http.server 8000
```

Open `http://localhost:8000`.

## Publication note

This is a structured documentation baseline generated from the supplied architecture, capability, security, integration, release, and inventory artifacts. Field-level model details and endpoint-level contracts must be validated from the implementation source before production publication.
