### 📝 Bug Report Template
- **Title**: [BUG] Summary of the problem
- **Description**: Detailed explanation of what happened.
- **Steps to Reproduce**: 1, 2, 3...
- **Expected Outcome**: What should have occurred.
- **Environment**: Local, QA, or Prod.
- **Logs**: Attach relevant traceback or browser console logs.
